# Agentic RAG System for Dairy Science

Welcome to the repository for the **first-ever Agentic Retrieval-Augmented Generation (RAG) System** designed specifically for Dairy Science! This innovative system retrieves information from scientific literature and, if the information is not found, activates a web search to ensure accurate and reliable results. This approach significantly reduces the risk of hallucination, making it a powerful tool for researchers and professionals in the field.

## Key Features

- **Literature Retrieval**: The system searches through a vast database of scientific literature to find relevant information, and **provides references**
- **Web Search Fallback**: If the desired information is not found in the literature, the system automatically activates a web search to retrieve the necessary data.
- **Hallucination Prevention**: By integrating judges/graders powered by reasoning LLMS, the system minimizes the risk of generating inaccurate or fabricated information.
- **Flowchart Logic**: A detailed flowchart is included to demonstrate the system's overall flow.
